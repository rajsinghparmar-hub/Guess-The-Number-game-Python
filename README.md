# Number Guessing Game (Python)

This is a simple Python-based **Number Guessing Game**.

The program randomly generates a number between **1 and 100**, and the user tries to guess it correctly.

---

## How It Works

- A random number is generated using Python  
- User enters a guess  
- Program gives hints:
  - Too small → try a bigger number  
  - Too big → try a smaller number  
- Type **Q** to quit the game  
- Correct guess ends the game
